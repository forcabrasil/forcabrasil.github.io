# Forca Brasil - Site Oficial

Site oficial do aplicativo **Forca Brasil**, um jogo clássico de adivinhação de palavras para Android.

## 📱 Sobre o Aplicativo

Forca Brasil é um jogo de adivinhação onde você tenta adivinhar palavras em português antes que o boneco seja desenhado completamente.

- **Nome do Pacote**: com.edilson.jogo
- **Plataforma**: Android
- **Disponível em**: [Google Play Store](https://play.google.com/store/apps/details?id=com.edilson.jogo)

## 🚀 Como usar

1. Clone o repositório:
```bash
git clone https://github.com/forcabrasil/forcabrasil.github.io.git
cd forcabrasil.github.io
```

2. Abra `index.html` no navegador ou acesse o site em produção

3. Para fazer alterações:
```bash
git add .
git commit -m "Descrição da mudança"
git push origin main
```

## 📝 Customizações Necessárias

Antes de publicar, atualize:

1. **index.html** - Substitua `seu-email@example.com` pelo seu email real
2. **Contact section** - Adicione seu email real
3. **Footer** - Atualize com seu nome/dados
